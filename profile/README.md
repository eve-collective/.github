# EVE Collective

**Open-source tools, developer APIs, and data infrastructure for New Eden.**

The **EVE Collective** is an open-source project dedicated to building tools, APIs, and software around [EVE Online](https://www.eveonline.com/). 

Currently built and maintained as an independent solo developer effort, the goal is to provide capsuleers, alliances, and third-party developers with transparent, reliable, and freely accessible tools across New Eden.

---

## Principles

- **Open Source & Open Data**: Everything built here is public, transparent, and freely available under open licenses.
- **Fair Play & EULA Compliance**: Strictly compliant with Fenris Creations (FC) developer agreements and Terms of Service. All software is built for out-of-game intelligence, analysis, and developer tooling—never botting or automated in-game play.
- **Open to Collaboration**: While currently a solo effort, feedback, feature ideas, and pull requests from fellow pilots and developers are always welcome.
